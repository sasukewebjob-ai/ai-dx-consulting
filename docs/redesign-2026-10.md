# AIコンサルLP 作り直しの設計（2026-10-11）

ユーザーの依頼：デザインを一新し、Codexの画像と、すでに作ったシステムの画面を使って超グレードアップする。
方針（ユーザー了承）：ライトザライトのLP（夜の灯り）とは別の、明るく信頼感のある顔。業務効率化と研修の2つの入口は残す。
画面：デモ8つ（架空のお店）＋運営中のしくみ（名前・中身を架空にして再現／本物の画面があれば差し替え／画面にしにくいものは文字）。
※このリポジトリは公開。顧客名・面談記録は書かない。

## 1. デザイン
- ねらう印象：実務に強い、清潔で頼れる相談役。「作ったものを、そのまま見せる人」
- 背景は白と薄いグレー、文字は紺。業務効率化＝ティール、研修＝青で区別。行動（LINE）は深い緑
- うっすら方眼（設計図）の背景で「しくみを設計する」空気
- 見出し：Zen Kaku Gothic New（太字）／本文：Noto Sans JP／数字・欧文：Outfit

## 4. Codex に作ってもらう画像と理由
| 画像 | 置く所 | なぜ要るか |
|---|---|---|
| `img/before-desk.webp`：紙の申込書・付箋・電卓・表計算の画面がある事務机（人物なし） | 4 Before | 「毎日の手作業」の今を一目で伝える。Afterは本物の画面で見せるので、Beforeだけをイメージにする |
| `img/training.webp`：会議室で数人がノートPCを開き、画面を指さして教える手元（顔なし） | 8 AI研修 | 「一緒に手を動かす研修」を見せる。企業研修の本物の写真はお客さんの情報になるので使えない |
| `ogp.jpg`（1200×630）：デモの画面に見出しを重ねる | SNSで共有したとき | 文字は画像AIに描かせず Claude Code が重ねる |

- AIの画像は「イメージ」と明記する。人物は顔が分からない形。元のPNGは `originals/ai/`（git管理外）
