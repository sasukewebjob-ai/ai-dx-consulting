# AI・DXコンサルLP

個人事業主・経営者向けに、AI研修・AI導入支援・AI内製化支援とGASによる業務自動化を紹介する根津仁志のLPです。名刺からの訪問者を中心に、公式LINEでの初回無料相談へつなげます。

- 公開先：<https://sasukewebjob-ai.github.io/ai-dx-consulting/>
- 相談先：<https://lin.ee/NFymCKmH>
- 制作実績：<https://sasukewebjob-ai.github.io/portfolio/>

## ローカルで見る

`index.html` をブラウザで開きます。ビルド・ライブラリのインストールは不要です。`profile.jpg` を同じフォルダに置いてください。

### GASによる業務自動化の追加

2026-09-10、ユーザー指定により `../ポートフォリオ/index.html` の制作情報をもとに追加。冒頭・AI導入支援・専用欄・実装事例・FAQ・検索/SNS向け説明に反映しました。

- LINEタスク管理、面談リマインド、イベントWeb申込：本番・実イベントで運用。
- 店舗の予約カレンダー・空き枠管理：テスト・デモ段階。本番実績として扱わない。
- ランキング戦の自動集計、Gmail受信トレイ整理：制作済み。
- GmailのGAS処理は既存メールの整理。新着の継続的な振り分けは標準フィルタを使用。
- GASはAI導入支援内の実装内容。既存の3サービス構成を維持し、AIを使わない自動化のみの相談にも対応することを明記。
- GASの概要は [Google公式ドキュメント](https://developers.google.com/apps-script/overview) で確認。

### デザイン・操作

- グリーン・ゴールド・生成りの配色を継承し、見出し・文字サイズ・余白を整理。
- 3つの支援を「向いている状況・支援内容・手元に残るもの」で比較。
- スマートフォンでは1列で読み進め、タブレットでは内容に応じて2列へ切り替え。
- FAQと試算は標準の `details` / `summary`。JavaScriptが無効でも読めます。
- 追従相談ボタンはスマートフォンで冒頭を過ぎた後に表示し、最後の相談欄が近づくと隠れます。
- 文字を透明にして登場を待たせる処理は廃止。動きを減らす端末設定にも対応します。
