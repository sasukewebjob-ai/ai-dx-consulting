# AI・DXコンサルLP

個人事業主・経営者向けに、AI研修・AI導入支援・AI内製化支援を紹介する根津仁志のLPです。名刺からの訪問者を中心に、公式LINEでの初回無料相談へつなげます。

- 公開先：<https://sasukewebjob-ai.github.io/ai-dx-consulting/>
- 相談先：<https://lin.ee/Y7OfHPe>
- 制作実績：<https://sasukewebjob-ai.github.io/portfolio/>

## ローカルで見る

`index.html` をブラウザで開きます。ビルド・ライブラリのインストールは不要です。`profile.jpg` を同じフォルダに置いてください。

## 2026-09-10 ブラッシュアップ

### 改善した課題

元ページでは支援内容の説明が重複し、3つのサービスの違いを把握しにくくなっていました。時間削減の訴求と試算の注記も離れていたため、実績と参考値を分けて読める構成に改めました。

### 新しい構成

1. 支援の概要と担当者の顔・支援スタイル
2. 状況に合う支援への入口
3. AI研修・AI導入支援・AI内製化支援の比較
4. 「超伴走型」の具体的な進め方
5. LINEタスク管理・見積書・イベント申込の実装事例
6. 業務別の時間削減試算（開閉式）と業種別の活用イメージ
7. プロフィール・掲載・登壇実績
8. 相談から実装までの流れ
9. FAQ 8問
10. 無料相談への案内

### デザイン・操作

- グリーン・ゴールド・生成りの配色を継承し、見出し・文字サイズ・余白を整理。
- 3つの支援を「向いている状況・支援内容・手元に残るもの」で比較。
- スマートフォンでは1列で読み進め、タブレットでは内容に応じて2列へ切り替え。
- FAQと試算は標準の `details` / `summary`。JavaScriptが無効でも読めます。
- 追従相談ボタンはスマートフォンで冒頭を過ぎた後に表示し、最後の相談欄が近づくと隠れます。
- 文字を透明にして登場を待たせる処理は廃止。動きを減らす端末設定にも対応します。

## 更新時の注意

- このLPのLINEリンクは `https://lin.ee/Y7OfHPe` です。別サイトの相談先と混同しないでください。
- ふりがなは「ねつ ひとし」。主軸の表現は「超伴走型」。
- 「開発実績30件以上」は既存の確定表記を継承。ポートフォリオへのリンクには固定件数を付けていません。
- 数値の時間削減は試算です。実測値・保証・顧客の導入成果として表示しないでください。
- 業種別の説明は活用イメージ。各業種への導入実績として扱わないでください。
- YouTube登録者は「情報発信・運用の実績」。AIチャンネルの実績とは表現しません。
- プロフィール・実績の数値は既存の掲載情報を引き継いでいます。最新状況の再調査は行っていません。
- 面談記録由来の素材ファイルは内部資料です。実名・未承認の事例を公開ページへ追加しないでください。
